# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, in full:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

The short version: be kind, be patient, assume good faith, and remember the
person on the other end is probably here because they want to learn something
or help someone else learn. Harassment, hate, and bad-faith participation are
not tolerated — in the app's community features, in repository discussions,
or anywhere the project gathers.

Enforcement contact: **marcuskidan@gmail.com**. Reports are handled
confidentially. Consequences follow the Covenant's enforcement guidelines,
from correction to permanent ban (including revocation of maintainer roles).
